# Security Policy

## Reporting a vulnerability

Please **do not open a public issue** for security vulnerabilities.

Instead, use one of these private channels:

- **GitHub private vulnerability reporting**: go to the repository's _Security_ tab → _Report a vulnerability_.
- **Email**: <xavi.anguera@aisvision.com>

Include steps to reproduce, the affected version, and your OS. You will receive an acknowledgement as soon as possible, normally within a few days.

GitBranch keeps your GitHub token in the operating-system keyring only, never logs it, and sends no telemetry. Reports about credential handling, the git command runner (argument injection, shell escapes) or the auto-updater are especially welcome.

## Supported versions

Only the latest release receives security fixes.
